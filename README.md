# Cloud Engineering Journey

This is where I keep track of what I'm learning as I work through cloud engineering and Linux systems administration on my own, outside of any formal course.

I started with the basics — Linux command line, file permissions, users, processes — before moving into AWS. Right now that means working through core services like IAM, EC2, and S3, along with the underlying concepts like AWS's global infrastructure (regions, availability zones) and how the different cloud service models (IaaS, PaaS, SaaS) actually differ in practice. I'm currently working toward the AWS Certified Cloud Practitioner exam.

## What's in here

- **Linux basics** — permissions, process management, networking commands, basic firewall and SSH setup
- **AWS work** — notes and small projects as I go through core services, plus anything I deploy hands-on (starting with a basic EC2 web server)
- **Scripts** — small bash scripts, mostly automation for things I found myself doing repeatedly
- **Learning notes** — dated entries on what I worked on, what confused me, and how I eventually figured it out

## Why I'm doing it this way

I'd rather have a record of things I actually built and broke and fixed than just a list of courses I sat through. A lot of this is going to be rough or incomplete at first — that's kind of the point, it's a record of the process, not a highlight reel.

## Notes

This gets updated as I go, roughly alongside whatever I'm currently working through. Older entries might look pretty basic compared to newer ones — that's just the learning curve showing.
